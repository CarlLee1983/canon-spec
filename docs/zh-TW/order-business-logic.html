      Invariant 分組

      Identity 與 ownership · 4
      • Sales 配置唯一 Order ID
      • Customer authority 驗證關聯
      • Order currency 建立後固定
      • 每個 Item 有穩定且唯一的 Item ID
      Quoted Item 與 calculation · 6
      • Quantity 大於零且完全等於 Pricing 接受值
      • 每次加入都建立 distinct Item，不自動合併
      • Item 保存完整 Quote snapshot
      • Item subtotal 以 Pricing 結果為權威
      • Unit Price 與 subtotal 可為零但不可為負數
      • Total 是同幣別 authoritative subtotals 的總和
      Lifecycle · 4
      • submitted 必須非空
      • submitted Items immutable
      • cancelled state 與 Items immutable
      • Cancel Order 僅代表提交前取消
      Idempotency 與 Event · 3
      • 相同 normalized request replay 回傳原結果
      • 不同 request 重用 ID 回傳 COMMAND_ID_CONFLICT
      • 第一次成功提交只產生一次 OrderSubmitted occurrence
